# Retained catalog similarity dispatch

`CatalogCommand::RequestSimilarity` accepts a private, immutable `SourceSimilarityRequest` plus a `SimilarityCancellation`. Construction rejects malformed paths, foreign-length source IDs, zero lifecycle/query generations, duplicates, anchor candidates, more than 64 candidates, paths longer than 4096 bytes and combined paths over 64 KiB. The request describes an explicit set, not a complete library search.

The existing catalog worker uses strict read-only `current_revision()` (never the mutation-renewing command accessor) and obtains its full owner-issued revision and genuine file observations, requiring supported audio, stable object identity and full content hash. It builds current `File / AnalysisFeatures / features-v1` targets using the audited manifest revision as source generation and calls the production query in `SOURCE_SIMILARITY_QUERY.md`. It does not publish targets, queue analysis, mutate readiness, open another database or traverse the source. Missing candidate payloads remain unavailable; missing anchor descriptors and stale/unknown identities produce bounded typed failures.

Each command reserves one event, its actual bounded input bytes and 1 MiB of the existing aggregate 32 MiB read-result budget. Result custody includes the request, full query, target rows/keys and observations. At most 65 observations retain source identity (256 bytes), root/database/binding identities (each capped at 1024 bytes), object identity (1024 bytes), hash (64 bytes) and a share of the 64 KiB path budget. Three target copies per file and fixed artifact key/reference strings, four path copies, 65 bounded revision/observation copies and fixed structural overhead fit the conservative 1 MiB reservation. Five optional scores per candidate are inline fixed storage (at most 2560 bytes
for 64 rows on this target). A compile-time conservative bound includes four
64 KiB path copies, 65 copies of 10 KiB bounded nonpath identity text and the
actual result/query/row/target/observation structural sizes; it must fit the
unchanged 1 MiB credit. Growing those structures beyond the credit fails compilation.
Publication fence clones retain shared weak/Arc custody and bounded generated owner identities. Failed or cancelled execution releases unused credits; queued results retain output credit until dequeue/drop/close. The aggregate input and result guards also apply when the command channel has space.

Cancellation is bound to the registered source's existing attempt token. Source retirement or a later source attempt cancels prior query delivery. Precancelled requests do not replace another attempt token. Successful output has a retained publication fence; delivery checks cancellation and owner liveness using memory only. Owner observation SQL checks run on the background worker before publication. UI consumers must compare the complete captured request, current cached source/root/revision and query generation before installation and every render. `SourceSimilarityResult::query()` is a cheap read of exact owner context; `is_current_for()` performs SQL and belongs on a background owner/read worker.

An accepted unknown/stale/expired source request reports a bounded diagnostic without a source-publication fence, never a successful projection. Other execution failures also remain exact-caller diagnostics, not source qualifications. Successful results require the retained fence. Shutdown and explicit cancellation discard projection. A result is a point-in-time metadata observation. It grants no physical effect authority and does not certify that later external writes are impossible.

Both artifact lookup methods borrow `readiness_store_read_only()`, and nested artifact lookup validates `ReadinessOwnership` in strict read-only mode before and after SQL. Mutation validation and publication still use the original renewal behavior. A real near-expiry lease regression first reproduced control-writer renewal with the old mutation-qualified accessor, then verifies unchanged lease expiry and DB/WAL bytes; expired ownership remains rejected without renewal.

Portable validation uses actual `CatalogService` registration/audit, real WAVs, production analysis/payload publication and the existing descriptor scorer. Tests cover exact scoring/unavailable rows, unchanged database/WAL bytes, stale revision/missing anchor, pre-cancellation, queued cancellation, retired owner, constructor budgets and a real paused worker with 32 reserved requests, Full rejection and credit release.
